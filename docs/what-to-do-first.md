## Suggested “version 1” implementation plan (architecture-first)

1. Auth (OIDC), user profiles, friendships.
2. Routines + check-in creation.
3. Media pipeline (presigned upload + thumbnails + retention).
4. Feed (friends’ check-ins).
5. Judgments + Joker flow (deadline + final verdict computation).
6. Messaging + WebSocket.
7. Notifications + reminders.
8. Hardening: rate limits, abuse controls, account deletion.
